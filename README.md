# 🌴 Kerala 3D Farm Simulator (കേരള 3D ഫാമിംഗ് സിമുലേറ്റർ)

A realistic 3D open-world Kerala farming simulation game featuring real-time multiplayer, authentic Kerala paddy fields (വയൽ), crop progression, and village environments.

## 🌟 Key Features
- **Authentic Kerala Agriculture**: Flooded paddy fields (ഞാറു നടീൽ, കതിരിടൽ, കൊയ്ത്ത്), highland crops (വാഴ, കപ്പ), vegetable trellises.
- **Open World Village Map**: Roads, earthen bunds (വരമ്പുകൾ), water canals, traditional tile-roof houses, and village market.
- **Realistic 3D Human Avatar**: Rigged 3D characters with motion-captured skeletal animations (Idle, Walk, Run).
- **Time & Seasonal System**: Seasons (വിരിപ്പ്, മുണ്ടകൻ, പുഞ്ച) with dynamic atmospheric weather.
- **Cross-Platform Multiplayer**: Real-time room synchronization via WebSockets (playable on PC & Mobile).
- **Local & Cloud Persistence**: State saves seamlessly.

## 🚀 Running the Game Locally
```bash
# Start server
python server.py
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
